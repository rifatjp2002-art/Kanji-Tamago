## 📖 পরিচিতি ও মূল দর্শন (About the Project)

**Kanji Tamago A1-B1 (漢字たまご)** মূলত জাপানে বসবাসরত প্রবাসী, শিক্ষার্থী এবং জাপানি ভাষা অনুরাগীদের জন্য বাস্তব জীবনের উপযোগী কাঞ্জি শেখার একটি আধুনিক ইন্টারেক্টিভ এডুকেশনাল প্ল্যাটফর্ম। গতানুগতিক বিরক্তিকর মুখস্থবিদ্যার বদলে জাপানের সুপারমার্কেট, ট্রেন স্টেশন, কনভিনিয়েন্স স্টোর (Konbini), পার্ট-টাইম কাজ (Baito), রেস্তোরাঁ, ডাক্তারখানা ও অফিস-আদালতের মতো বাস্তব প্রেক্ষাপটে কাঞ্জি আত্মস্থ করার পদ্ধতি এখানে অনুসরণ করা হয়েছে।

## ✨ প্রধান ও নতুন বৈশিষ্ট্যসমূহ (Core Features)

### ১. 📚 ৩০টি স্বয়ংসম্পূর্ণ লেসন (A1 থেকে B1 / N5 থেকে N3)
- **বাস্তব জীবনমুখী কারিকুলাম:** দৈনন্দিন জাপানি জীবনের ৩০টি অতি প্রয়োজনীয় বিষয় নিয়ে সাজানো।
- **পূর্ণাঙ্গ কাঞ্জি ডেটা:** প্রতিটি কাঞ্জির জন্য অন'ইয়োমি (On'yomi), কুন'ইয়োমি (Kun'yomi), অর্থ (বাংলা ও ইংরেজি), এবং বাস্তব জীবনের ৫-৬টি গুরুত্বপূর্ণ ভোকাবুলারি ও উদাহরণ বাক্য।
- **দ্বৈত-ভাষা মেমোরি টিপস (Bengali Mnemonics):** প্রতিটি কাঞ্জির গঠন ভেঙে বাংলা গল্পের মাধ্যমে সহজে মনে রাখার বিশেষ **"তামাগো টিপ" (Visual Story)**।
- **নেটিভ অডিও ইঞ্জিন:** ব্রাউজারের নেটিভ `SpeechSynthesis` ইঞ্জিন দ্বারা নিখুঁত জাপানি উচ্চারণ (`ja-JP`) শোনার সুযোগ।

### ২. 🎯 অ্যাডভান্সড কুইজ ইঞ্জিন ও নতুন ৩টি পাওয়ারফুল ফিচার (৩,৬৮২+ প্রশ্ন)
অ্যাপের কুইজ ইঞ্জিনটি শিক্ষার্থীকে শুধু পরীক্ষা নেওয়ার জন্য নয়, বরং পরীক্ষার মাধ্যমে পারফেক্ট করার জন্য ডিজাইন করা হয়েছে:

1. **🏛️ JLPT রিয়েল এক্সাম মোড (JLPT Real Exam Format - 漢字読み & 表記):**
   - অফিশিয়াল জাপানিজ ল্যাঙ্গুয়েজ প্রফিসিয়েন্সি টেস্ট (JLPT N5–N3)-এর অনুরূপ প্রশ্ন ফরম্যাট।
   - **প্যাটার্ন ১ (漢字読み):** বাস্তব বাক্যের ভেতর বন্ধনীতে থাকা কাঞ্জিটির সঠিক হিরাগানা রিডিং নির্বাচন।
   - **প্যাটার্ন ২ (表記):** বাক্যের ভেতর বন্ধনীতে থাকা হিরাগানার সঠিক কাঞ্জি রূপ বাছাই।
   - প্রতিটি প্রশ্নে পূর্ণাঙ্গ বাংলা ব্যাকরণ ও সমাধান ব্যাখ্যা।

2. **⏱️ স্পিড টাইমার ও কাউন্টডাউন মোড (Speed Drill):**
   - **আনলিমিটেড মোড:** কোনো সময়ের চাপ ছাড়া ধীরে-সুস্থে শেখার সুযোগ।
   - **১৫ সেকেন্ড স্পিড ড্রিল:** দ্রুত ডিসিশন নেওয়ার দক্ষতা বাড়াতে চোখের পলকে উত্তর দেওয়ার র‌্যাপিড-ফায়ার চ্যালেঞ্জ।
   - **৩০ সেকেন্ড স্ট্যান্ডার্ড টেস্ট:** অফিশিয়াল পরীক্ষার অনুকরণে নির্দিষ্ট সময়ের মধ্যে উত্তর দেওয়ার অভ্যাস।
   - অ্যানিমেটেড পালসিং কালার বার (সবুজ ➔ হলুদ ➔ লাল) এবং সময় শেষ হলে অটোমেটিক নেগেটিভ মার্ক ও রিভিউ সিস্টেমে অন্তর্ভুক্তি।

3. **🧠 স্মার্ট মিসটেক ব্যাংক ও রি-টেস্ট (Mistake Notebook & Recovery):**
   - কুইজ চলাকালীন ভুল হওয়া সমস্ত প্রশ্ন স্বয়ংক্রিয়ভাবে ব্রাউজারের লোকাল স্টোরেজে সেভ হয়ে যায়।
   - কুইজ শেষে বা কুইজ সেটআপ থেকে **"ভুল প্রশ্নগুলো পুনরায় প্র্যাকটিস করুন"** অপশনে ১-ক্লিকে শুধু দুর্বল কাঞ্জিগুলো রি-টেস্ট দেওয়ার সুযোগ।
   - পুনরায় প্র্যাকটিস করার সময় সঠিক উত্তর দিলে তাৎক্ষণিক উৎসাহমূলক মেসেজ: *"🎉 অসাধারণ! ভুল কাঞ্জিটি সফলভাবে শুধরে নিয়েছেন!"* এবং কাঞ্জিটি ভুল ব্যাংক থেকে ক্লিন হয়ে যায়।
   - কুইজের ভেতর ১৩টিরও বেশি ফিল্টার মোড (কাঞ্জি ➔ কানা, কানা ➔ কাঞ্জি, অন'ইয়োমি, কুন'ইয়োমি, অর্থ, ভোকাবুলারি, স্ট্রোক সংখ্যা, বাস্তব সাইনবোর্ড সিচুয়েশন ইত্যাদি)।

### ৩. ✍️ ডুয়াল-মোড ক্যালিগ্রাফি ড্রয়িং স্টুডিও (Writing Canvas)
- **🎴 শ্লেট মোড (Slate Mode):** সোনালী ও সাদা চকের মতো ডার্ক ক্যানভাসে গ্লোয়িং নিয়ন স্ট্রোকে লেখার অনুভূতি।
- **📜 ট্র্যাডিশনাল পেপার মোড (Hanji Paper Mode):** ঐতিহ্যবাহী জাপানি হানশি পেপারের মতো ক্রিম ব্যাকগ্রাউন্ডে খাঁটি কালো সুমি (Sumi) কালিতে লেখার অনুভূতি।
- স্পষ্ট ব্যাকড্রপ ট্রেসিং গাইড, স্ট্রোক অর্ডার গাইডলাইন এবং ফ্রি-হ্যান্ড ক্যালিগ্রাফি আর্ট প্র্যাকটিস।

### ৪. 🎴 স্মার্ট ফ্ল্যাশকার্ড ও অ্যাক্টিভ রিকল (SRS Flashcards)
- সহজ, মধ্যম ও কঠিন রেটিংয়ের মাধ্যমে পারসোনালাইজড আত্মমূল্যায়ন।
- স্পেসবার বা এন্টারে ফ্লিপ করে পেছনের ভোকাবুলারি, উদাহরণ বাক্য ও মেমোরি টিপস দেখার সুবিধা।
- সম্পূর্ণ প্রগ্রেস কোনো বাহ্যিক সার্ভার ছাড়া আপনার নিজের ব্রাউজারে সংরক্ষিত থাকে।

### ৫. ⌨️ গ্লোবাল কীবোর্ড শর্টকাটস (Laptop / Desktop / Tablet)
- **ফ্ল্যাশকার্ডে:**
  - `Space` / `Enter` : কার্ড ফ্লিপ (সামনে / পেছনে)
  - `←` / `→` : আগের ও পরের কাঞ্জি কার্ড
  - `1`, `2`, `3` : কঠিন (Hard), মধ্যম (Medium), সহজ (Easy) রেটিং
  - `V` : জাপানি অডিও উচ্চারণ
  - `D` : সরাসরি ক্যালিগ্রাফি ড্রয়িং প্যাড ওপেন
- **কুইজে:**
  - `1 - 4` অথবা `A - D` : সরাসরি অপশন নির্বাচন
  - `Space` / `Enter` : পরবর্তী প্রশ্নে যাওয়া বা ফলাফল দেখা
  - `V` : বাক্যের অডিও উচ্চারণ শোনা
  - `H` : কঠিন হিসেবে বুকমার্ক বা ভুল ব্যাংকে চিহ্নিত করা

### ৬. 📱 সুপার-অপ্টিমাইজড প্রগ্রেসিভ ওয়েব অ্যাপ (PWA) ও অফলাইন আর্কিটেকচার
- **লো-এন্ড মোবাইল অপ্টিমাইজেশন:** কম র‍্যাম বা দুর্বল 3G/4G নেটওয়ার্কেও কোনো তোতলানো বা ল্যাগ ছাড়া মুহূর্তের মধ্যে অ্যাপ চালু হয়।
- **Stale-While-Revalidate ক্যাশিং:** সার্ভিস ওয়ার্কার ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে লেসন ও মিডিয়া ক্যাশ করে রাখে।
- **নিরাপদ ৬MB মেমোরি বাফার:** ক্যাশ ওভারফ্লো বা ব্রাউজার কোটা ইরর এড়াতে `purgeOnQuotaError` এবং সর্বোচ্চ ৬MB প্রি-ক্যাশ সাইজ কনফিগারেশন।
- **স্মার্ট ইনস্টল বাটন:** অ্যাপ ইনস্টল করা থাকলে হোম স্ক্রিন ও সেটিংস মেনু থেকে ইনস্টল বাটন ও ব্যানার নিজে থেকেই নিখোঁজ হয়ে যায়, ফলে অ্যাপ একদম ক্লিন নেটিভ অ্যাপের মতো দেখায়। ভবিষ্যতে আনইনস্টল করলে স্বয়ংক্রিয়ভাবে বাটনটি ফিরে আসে।

## 📱 মোবাইলে ও কম্পিউটারে অ্যাপ ইনস্টল করার নিয়ম (PWA Installation)

Kanji Tamago একটি আধুনিক **Progressive Web App (PWA)**। গুগল প্লে-স্টোর বা অ্যাপ স্টোরে না গিয়ে সরাসরি ব্রাউজার থেকেই ১-ক্লিকে ইনস্টল করে ব্যবহার করা যায়:

### 🤖 Android ফোনে (Chrome / Samsung Internet):
1. **[https://rifatjp2002-art.github.io/Kanji-Tamago/](https://rifatjp2002-art.github.io/Kanji-Tamago/)** লিংকে প্রবেশ করুন।
2. হোম পেজের সোনালী ব্যানারে **"📱 ১-ক্লিকে অ্যাপ ইনস্টল করুন"** বাটনে ট্যাপ করুন।
3. অথবা ব্রাউজারের ওপরের ডানদিকের **৩-ডট মেনু (⋮)** ট্যাপ করে **"Install app"** বা **"Add to Home screen" (হোম স্ক্রিনে যোগ করুন)** চাপুন।

### 🍎 iPhone / iPad-এ (Safari ব্রাউজার):
1. Safari ব্রাউজারে ওয়েবসাইটটি খুলুন।
2. নিচের টুলবারের মাঝখানের **Share (শেয়ার ⎋)** আইকনে চাপ দিন।
3. একটু নিচে স্ক্রল করে **"Add to Home Screen" (হোম স্ক্রিনে যোগ করুন)** অপশনে ট্যাপ করে উপরে ডানপাশের **"Add"** চাপুন।

### 💻 Laptop / Desktop-এ (Chrome / Edge / Brave):
1. ব্রাউজারের অ্যাড্রেস বারের ডান পাশে ছোট **ইনস্টল আইকন (⊕)** দেখতে পাবেন, সেখানে ক্লিক করুন।
2. অথবা ব্রাউজার মেনু থেকে **"Install Kanji Tamago"** সিলেক্ট করুন।

## 🛠️ প্রযুক্তিগত বৈশিষ্ট্য ও আর্কিটেকচার (Technical Stack)

- **Frontend Core:** React 19 + TypeScript (Strict Type Safety, No `any`).
- **Styling & Design System:** Tailwind CSS v4 (Mobile-First, Neo-Brutalist & Glassmorphic Accents).
- **Icons & Assets:** Zero external SVG dependency (হ্যান্ডক্রাফটেড ইনলাইন এসভিজি ও জাপানি ইউনিকোড যাতে কোনো বান্ডল ব্লোট না হয়)।
- **Audio Engine:** Native Web SpeechSynthesis API (`ja-JP` Japanese voice synthesis)।
- **Service Worker & PWA:** `vite-plugin-pwa` + Workbox (`StaleWhileRevalidate`, `skipWaiting`, `clientsClaim`, `cleanupOutdatedCaches`)।
- **Persistence:** LocalStorage Engine (Streak tracking, Kanji Mastery Status, Mistake Bank, Quiz History).
- **Security:** 100% Client-Side Architecture (কোনো থার্ড-পার্টি ট্র্যাকার বা এক্সটার্নাল কুয়েরি নেই, সম্পূর্ণ নিরাপদ ও প্রাইভেট)।

## 💻 লোকাল মেশিনে রান করার নিয়ম (Local Development)

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/rifatjp2002-art/Kanji-Tamago.git
cd Kanji-Tamago

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. লোকাল ডেভলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev

# ৪. প্রোডাকশন বিল্ড তৈরি করুন
npm run build

# ৫. টাইপ ও সিনট্যাক্স যাচাই করুন
npm run lint
```

## 🚀 গিটহাবে পুশ ও অটো-ডিপ্লয়মেন্ট (Push to GitHub & Auto Deploy)

এই প্রজেক্টে **GitHub Actions CI/CD** সক্রিয় করা আছে। আপনি শুধুমাত্র আপনার রিপোজিটরিতে কোড পুশ করলেই স্বয়ংক্রিয়ভাবে বিল্ড সম্পন্ন হয়ে **GitHub Pages**-এ লাইভ হয়ে যাবে।

```bash
# গিট কমিট ও পুশ করার নিয়ম:
git add .
git commit -m "feat: add JLPT real exam mode, countdown timer, and mistake recovery bank"
git push origin main
```
