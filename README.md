## 📖 পরিচিতি ও মূল দর্শন (About the Project)

**Kanji Tamago A1-B1 (漢字たまご)** মূলত জাপানে বসবাসরত প্রবাসী এবং জাপানি ভাষা শিক্ষার্থীদের বাস্তব জীবনের উপযোগী কাঞ্জি শেখানোর একটি অনন্য প্ল্যাটফর্ম। গতানুগতিক মুখস্থবিদ্যার বদলে জাপানের সুপারমার্কেট, ট্রেন স্টেশন, রেস্তোরাঁ, ডাক্তারখানা, আবহাওয়া ও খবরের কাগজের মতো বাস্তব প্রেক্ষাপটে কাঞ্জি আত্মস্থ করার পদ্ধতি এখানে অনুসরণ করা হয়েছে।

### ✨ প্রধান বৈশিষ্ট্যসমূহ (Core Features)

1. **📚 ৩০টি স্বয়ংসম্পূর্ণ লেসন (A1 থেকে B1 / N5 থেকে N3):**
   - দৈনন্দিন জীবনের বাস্তব প্রেক্ষাপটভিত্তিক কারিকুলাম।
   - প্রতিটি কাঞ্জির জন্য অন'ইয়োমি (On'yomi), কুন'ইয়োমি (Kun'yomi), অর্থ (বাংলা ও ইংরেজি), এবং বাস্তব জীবনের ৫-৬টি গুরুত্বপূর্ণ ভোকাবুলারি ও উদাহরণ বাক্য।
   - বাংলা গল্পের মাধ্যমে কাঞ্জি মনে রাখার বিশেষ **"তামাগো টিপ" (Mnemonic Story)**।

2. **🎯 ডায়নামিক কুইজ ইঞ্জিন (৩,৬৮২টি ইউনিক প্রশ্ন পুল):**
   - ১২টিরও বেশি আলাদা কুইজ মোড (কাঞ্জি ➔ কানা, কানা ➔ কাঞ্জি, অন'ইয়োমি, কুন'ইয়োমি, অর্থ, ভোকাবুলারি, শূন্যস্থান পূরণ, স্ট্রোক কাউন্ট, এবং বাস্তব সাইনবোর্ড সিচুয়েশন)।
   - কাস্টম প্রশ্ন সংখ্যা (১০, ২০, ৫০, ১০০, ২০০ অথবা সম্পূর্ণ পুল)।
   - প্রতিটি প্রশ্নের সাথে সঠিক উত্তর এবং পূর্ণাঙ্গ বাংলা ব্যাখ্যা।
   - ভুল হওয়া কাঞ্জিগুলো সরাসরি ফ্ল্যাশকার্ডের "কঠিন তালিকা"-তে সেভ করার সুবিধা।

3. **✍️ ডুয়াল-মোড ক্যালিগ্রাফি ড্রয়িং স্টুডিও (Writing Pad):**
   - **🎴 শ্লেট মোড (Slate Mode):** সোনালী বা সাদা চুন দিয়ে ডার্ক ক্যানভাসে গ্লোয়িং স্ট্রোক আঁকার মোড।
   - **📜 কাগজ মোড (Traditional Paper Mode):** জাপানি ঐতিহ্যবাহী হানশি পেপারের মতো ক্রিম ব্যাকগ্রাউন্ডে খাঁটি কালো সুমি (Sumi) কালিতে লেখার অনুভূতি।
   - স্পষ্ট ব্যাকড্রপ ট্রেসিং গাইড এবং ফ্রি-হ্যান্ড প্র্যাকটিস অপশন।

4. **🎴 স্মার্ট ফ্ল্যাশকার্ড ও অ্যাক্টিভ রিকল (SRS Flashcards):**
   - সহজ, মধ্যম ও কঠিন রেটিংয়ের মাধ্যমে আত্মমূল্যায়ন।
   - কার্ড উল্টে অর্থ, ব্যাকরণ ও বাক্য চেক করার সুবিধা।
   - সম্পূর্ণ প্রগ্রেস আপনার ব্রাউজারের `localStorage`-এ অটো-সেভ হয়।

5. **⌨️ গ্লোবাল কীবোর্ড শর্টকাটস (Laptop / Desktop / Tablet Keyboard):**
   - **ফ্ল্যাশকার্ডে:**
     - `Space` / `Enter` : কার্ড ফ্লিপ (সামনে / পেছনে)
     - `←` / `→` : আগের ও পরের কার্ড
     - `১`, `২`, `৩` : কঠিন, মধ্যম, সহজ রেটিং
     - `V` : জাপানি অডিও উচ্চারণ
     - `D` : সরাসরি ড্রয়িং প্যাড ওপেন
   - **কুইজে:**
     - `1 - 4` অথবা `A - D` : অপশন নির্বাচন
     - `Space` / `Enter` : পরবর্তী প্রশ্ন / ফলাফল
     - `V` : বাক্যের অডিও
     - `H` : কঠিন হিসেবে বুকমার্ক

6. **📱 প্রগ্রেসিভ ওয়েব অ্যাপ (PWA) ও অফলাইন সাপোর্ট:**
   - মোবাইল বা ল্যাপটপে নেটিভ অ্যাপের মতো ১-ক্লিকে ইন্সটলযোগ্য।
   - সার্ভিস ওয়ার্কার দ্বারা সম্পূর্ণ ডেটা ক্যাশ থাকায় **ইন্টারনেট ছাড়াই ১০০% অফলাইনে চলে**।
   - লো-এন্ড ফোনে কোনো ল্যাগ বা মেমরি লিক ছাড়া দ্রুততম রেসপন্স।

7. **🛡️ এন্টারপ্রাইজ গ্রেড সিকিউরিটি:**
   - ১০০% ক্লায়েন্ট-সাইড স্ট্যাটিক আর্কিটেকচার।
   - কোনো এক্সটার্নাল ডাটাবেস বা ব্যাকএন্ড সার্ভার না থাকায় হ্যাকিং বা ডাটা ফাঁসের কোনো ঝুঁকি নেই।

## 🚀 গিটহাবে পুশ ও অটো-ডিপ্লয়মেন্ট (Push to GitHub & Auto Deploy)

এই প্রজেক্টে **GitHub Actions CI/CD** কনফিগার করা আছে। আপনি শুধুমাত্র আপনার রিপোজিটরিতে কোড পুশ করলেই স্বয়ংক্রিয়ভাবে ওয়েবসাইট বিল্ড হবে এবং **GitHub Pages**-এ লাইভ হয়ে যাবে!

### অটো ডিপ্লয়মেন্ট সেটআপ করার সহজ ধাপ:

1. **গিট ইনিশিয়ালাইজ ও রিমোট অ্যাড করুন:**
   ```bash
   git init
   git add .
   git commit -m "feat: complete Kanji Tamago A1-B1 release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/kanji-tamago.git
   git push -u origin main
   ```

2. **GitHub Pages পারমিশন অন করুন:**
   - আপনার GitHub রিপোজিটরি ওপেন করে **Settings** ➔ **Pages** ট্যাবে যান।
   - **Build and deployment** সেকশনের **Source** ড্রপডাউনে **"GitHub Actions"** সিলেক্ট করুন।
   - ব্যাস! প্রতিবার `main` বা `master` ব্রাঞ্চে পুশ করলেই `.github/workflows/deploy.yml` নিজে থেকেই সাইট বিল্ড করে লাইভ করে দেবে।
